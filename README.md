# HFSS Antenna Designs

A collection of antenna designs simulated in Ansys Electronics Desktop (HFSS) Student 2025 R2.4. Each design has its own folder with the design parameters, simulation results, and plots.

## Designs
| # | Antenna | Frequency | Key results |
|---|---|---|---|
| 1 | [Quarter-wave monopole](01-monopole-1ghz) | 1 GHz | S11 -18.48 dB, VSWR 1.27, about 5.1 dBi |

## Tools
- Ansys HFSS (Terminal network solution)
- Metrics reported: S11, VSWR, input impedance, Smith chart, 3D gain, E-plane pattern
